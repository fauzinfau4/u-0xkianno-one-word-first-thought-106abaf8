# One Word, First Thought

This entry is **psithurism**, the sound of wind whispering through leaves: its repeated sibilants make the word sound like its meaning, while the precise image gives it sensory vividness and a surprise beyond a familiar pick. It steers clear of expected “beautiful word” list entries such as *petrichor*, *serendipity*, *mellifluous*, and *ineffable*. Run `python3 main.py` to write the one-word entry to `/output/entry.txt`. This is original work created for this competition.

## Why this word

Psithurism is rare and vivid: its sibilants whisper like wind through leaves, so its sound carries its image. I avoided famous “beautiful word” picks like *petrichor* and *serendipity* because they are familiar choices.
